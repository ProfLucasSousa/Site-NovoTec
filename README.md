## 📖 Sobre o Projeto

O **InformaTec** é um portal educacional desenvolvido pelos alunos do 3º ano B do curso Técnico em Informática Para Internet (NOVOTEC) da E.E. Vicente Leporace. O projeto reúne conteúdos didáticos das disciplinas de Humanas e Linguagens do Ensino Médio, com o objetivo de auxiliar estudantes em sua jornada de aprendizado e preparação para o ENEM.

## ✨ Funcionalidades

- 📝 Conteúdos organizados por disciplina e ano/bimestre
- 🎥 Videoaulas complementares
- ✍️ Exercícios com respostas e explicações
- 📱 Design responsivo e acessível
- ♿ Integração com VLibras para acessibilidade
- 🔗 Links para materiais complementares externos

## 🚀 Como Usar

### Visualização Local

1. Clone o repositório:
```bash
git clone https://github.com/ProfLucasSousa/Site-NovoTec.git
```

2. Navegue até a pasta do projeto:
```bash
cd Site-NovoTec
```

3. Abra o arquivo `index.html` no seu navegador preferido.

### Hospedagem

O site é estático e pode ser hospedado em qualquer serviço de hospedagem web, como:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
